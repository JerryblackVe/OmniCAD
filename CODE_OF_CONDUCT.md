# Código de convivencia

OmniCAD es un proyecto abierto y queremos que cualquiera se sienta bienvenido a participar, sin importar su experiencia,
origen, identidad o forma de pensar.

## Lo que esperamos

- Respeto y buena fe, en issues, pull requests y cualquier conversación del proyecto.
- Críticas al trabajo, nunca a las personas. Explicá el porqué y, si podés, proponé una alternativa.
- Paciencia con quien recién empieza: todos empezamos alguna vez.
- Aceptar que una decisión técnica puede no salir como uno quería.

## Lo que no se acepta

- Insultos, acoso, discriminación o lenguaje sexualizado.
- Ataques personales, provocaciones o publicar datos privados de otra persona.
- Cualquier conducta que haga sentir inseguro a alguien en el proyecto.

## Qué pasa si alguien no lo respeta

Quienes mantienen el proyecto pueden editar o borrar comentarios, cerrar conversaciones y, si hace falta, bloquear a
quien no respete estas reglas. Para avisar de un problema, abrí un issue o escribí a quien mantiene el proyecto por su
perfil de GitHub ([@JerryblackVe](https://github.com/JerryblackVe)); se trata con discreción.
