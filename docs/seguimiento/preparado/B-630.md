# B-630 · La vista previa de Engrosar un filete se corta

## Fusion: «Thicken a surface»

1. **Design > Solid > Create > Thicken** abre el diálogo para crear un sólido desde una cara o superficie.
2. Desactivá **Chain Selection** para elegir caras o superficies específicas.
3. Elegí en el lienzo las caras que querés engrosar.
4. Ajustá **Thickness** arrastrando el manipulador o escribiendo el valor.
5. El espesor positivo engrosa hacia afuera; el negativo, hacia adentro.
6. **One Side** engrosa de un lado; **Symmetric**, a ambos lados por igual.
7. **Sharp Thicken** deja esquinas agudas; **Rounded Thicken** las redondea.
8. **Join**, **Cut** e **Intersect** combinan el resultado con un cuerpo existente.
9. **New Body** lo crea en el componente activo; **New Component** está disponible en diseños híbridos.
10. **OK** muestra el resultado; el espesor está limitado por la desaparición de una cara. La ayuda no da un plazo para la vista previa.
