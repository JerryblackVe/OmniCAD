## Resumen de Fusion

Fuente: ayuda oficial guardada, artículo **«Create a plane along path»** (Design › Solid › Construction geometry; `docs/fusion_docs/contenido/fusion-model/create-a-plane-along-path-6028958de7a.md`).

1. **Construct > Plane Along Path** abre el diálogo **Construction Geometry** con Type = Plane y Method = Along Path.
2. La **Path** es una arista, línea de boceto, cadena de aristas o eje de construcción.
3. El plano queda **normal (perpendicular) a la ruta** en el lugar elegido; la ayuda lo repite al final: «normal to the path».
4. Con arista/línea/cadena, el **Extent Type** es Proportional (fracción del largo), Absolute (mm) o To Object (pasa por una referencia).
5. Se puede arrastrar el asa **Distance** sobre la ruta, y también pasarse del extremo: el plano sigue recto por la tangente del último tramo.
6. Con un eje como Path se elige un Reference Object para anclar la posición.
7. **Resize**: Default ajusta el plano a la geometría elegida; Extended lo agranda para llenar la vista.
8. El plano se ve en el lienzo mientras se elige la distancia; al aceptar, «The new construction plane displays in the canvas, normal to the path».
9. Se usa para bocetar un perfil que después se barre por la ruta (el caso de la captura: onda + Barrido).
